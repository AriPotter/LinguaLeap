# **App Name**: LinguaLeap

## Core Features:

- Interactive Vocab: Vocabulary exercises with visual aids and audio pronunciation.
- Adaptive Quizzes: Spaced repetition quizzes with progress tracking.
- AI Pronunciation: AI-powered pronunciation tool that analyzes user speech and provides feedback.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a calming and trustworthy feel.
- Secondary color: Pale green (#90EE90) to indicate correctness and progress.
- Accent: Coral (#FF7F50) to highlight interactive elements and call to action.
- Clean and modern typography to ensure readability.
- Use intuitive icons to represent different exercise types and language features.
- Clean and intuitive layout with a focus on ease of navigation.
- Subtle animations and transitions to provide feedback and engagement.
